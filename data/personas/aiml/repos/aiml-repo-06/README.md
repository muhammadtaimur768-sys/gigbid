# evalkit

Small, production-tested service extracted from client work (saas). It exists because every prompt change was judged by vibes and regressions reached customers.

## Features

- Model evaluation-based core to prove the model beat the baseline
- Config via environment variables
- Tests for the main paths

## Quickstart

```bash
make install
make run
```

## Status

Used in production by one client; PRs welcome.
