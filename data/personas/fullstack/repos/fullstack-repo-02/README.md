# pinboard-live

Small, production-tested service extracted from client work (agency). It exists because the agency's planning lived in a spreadsheet that people overwrote.

## Features

- React.js-based core to build the component library and screens
- Config via environment variables
- Tests for the main paths

## Quickstart

```bash
make install
make run
```

## Status

Used in production by one client; PRs welcome.
