# rentql

Small, production-tested service extracted from client work (real estate). It exists because the web and mobile teams kept asking backend for new endpoints.

## Features

- Graphql-based core to give the mobile and web clients one flexible API
- Node.js-based core to run the backend services
- Config via environment variables
- Tests for the main paths

## Quickstart

```bash
make install
make run
```
