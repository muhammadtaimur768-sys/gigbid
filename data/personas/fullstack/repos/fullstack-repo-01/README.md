# billbird

Small, production-tested service extracted from client work (saas). It exists because the founder had a Figma file and a waiting list but no product.

## Features

- Next.js-based core to server-render the marketing and app pages
- Stripe-based core to handle subscriptions and invoices
- Config via environment variables
- Tests for the main paths

## Quickstart

```bash
make install
make run
```

## Status

Used in production by one client; PRs welcome.
